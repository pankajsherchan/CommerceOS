# Storefront Skeleton

`apps/storefront` is the first runnable CommerceOS surface.

## Commands

```bash
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## Scope

This app currently contains only:

- a minimal App Router layout
- a placeholder home page
- global baseline styles
- a Vitest smoke test

Commerce flows, navigation, auth, and the final shared theme system are
deliberately deferred to later units.
